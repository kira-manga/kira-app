## Pending expect/actual declarations (deferred to per-phase work)

The full Phase 8 scope per `migration/kmp-migration-plan.md` includes ~20 platform abstractions, most of which depend on later-phase code arriving in `commonMain`. Each is documented here with the target shape and the phase that lands it.

### Storage / preferences (Phase 8/11)

```kotlin
// commonMain (proposed)
expect class SettingsFactory() {
    fun create(name: String = "AppPrefs"): com.russhwolf.settings.Settings
}
```

- Android: backed by `SharedPreferencesSettings(context.getSharedPreferences(name, MODE_PRIVATE))`
- iOS: `NSUserDefaultsSettings(NSUserDefaults.standardUserDefaults)`
- Desktop: `PreferencesSettings(java.util.prefs.Preferences.userRoot().node(name))`

Wraps `multiplatform-settings 1.3.0` which already provides per-platform `Settings` types — only the constructor argument differs.
