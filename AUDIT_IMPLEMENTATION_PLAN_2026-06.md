## Principles

- **Small safe commits.** Each batch is one logical commit (some split into labelled sub-commits). Commit locally on `parity-fixes`; **never push**.
- **Compile + test gate after every batch** (3-target compile + the batch's module tests + `:app:testDebugUnitTest` whenever DI changes). A red gate blocks the next batch.
- **Untouchable:** owner WIP (`ui/.../home/HomeScreen.kt`, `MangaLekRepositoryv2.kt`, `MangaSource.kt`, `.idea/runConfigurations/iosApp.xml`) and read-only paths (`sources_repositry/`, `native-app/`). Where a fix's *consumption point* lives in a WIP file, ship the VM/adapter side and **defer** the screen wiring (flagged per-batch).
- **New code in rework modules** (`:core/:domain/:data/:platform/:presentation/:ui/:composeApp`); the only `:shared` edits are existing files the audit cited (Room DAOs in B6, legacy KDocs in B14).
- **Stop-for-approval checkpoints** (see review): **B6** is a hard stop (re-opens 4 Room DAOs); **B4/B5** are checkpoints; product-decision confirmations are called out in B5(#32 scope), B8(#10 delete semantics), B12(#16 search).
