Every screen — old vs new

Manga Details

Search

Downloads

History

Flat rows → “Recently read” header, clear date sections, rounded entry cards, and the floating nav.

Updates

Sources

Statistics

Plain number lists → a dashboard: overview stat card, weekly activity bars, ranked top-source bars, and status chips.
